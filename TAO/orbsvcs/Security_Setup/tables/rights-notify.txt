# Recommended required rights for the TAO Notification Service (Phase 3
# T2, R33): a draft for "ace-tao-setup rights sign --file rights-notify.txt",
# to review and change before signing.
#
#   get     read: QoS, properties, filters, constraints, admins, proxies
#   use     take part: obtain a proxy, connect, push or pull events,
#           suspend, resume and disconnect, offer and subscription changes
#   set     change: QoS, filters and constraints, filter callbacks,
#           priority and lifetime filters, create and destroy filters
#   manage  administer: create channels and admins, set a channel's admin
#           properties, destroy channels and admins, save the topology
#
# With grants-notify.txt: an observer can look, a participant can publish
# and subscribe and manage its own filters, a channel-admin can do all.
# Requests match the target's most-derived interface; the inherit lines
# give each interface its bases' lines.  CORBA's built-in operations need
# get unless listed.
